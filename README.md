# Site BRK Academia de Segurança Privada

O site é montado automaticamente a partir da pasta `src/` (GitHub Actions → GitHub Pages).

- Dados da escola (nome, telefone, horário, Instagram, autorização PF): `src/dados.json`
- Fotos: `src/assets/img/` (fachada.jpg, sala.jpg, estande.jpg, hero.jpg ...)
- Campos entre colchetes em `dados.json` ficam ocultos no site.
